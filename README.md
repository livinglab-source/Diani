## 🚀 Installation & Running

### 1. Jalankan Python

Buka **Terminal di VS Code**, lalu jalankan:

```bash
python mainlocalnew.py
```

Biarkan terminal tetap berjalan.

### 2. Jalankan HTML

Buka file:

```text
indexlocalnew.html
```

Kemudian **klik kanan → Open with Live Server**.

### 3. Cek Jaringan

Pastikan laptop terhubung ke **jaringan WiFi yang sama dengan IP CCTV**.

> **Penting:** Python dan HTML harus berjalan saat menggunakan aplikasi.
